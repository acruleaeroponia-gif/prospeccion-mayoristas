## 2. NORTE ESTRATÉGICO

Sistema de **testing → escala → iteración semanal** con matriz **DRO** (Dolores · Resultados · Objeciones). Cada semana: probar ángulos nuevos, escalar ganadores, matar perdedores.

### KPIs objetivo
| KPI | Objetivo | Actual (últimas 7 sem) |
|---|---|---|
| ROAS general | 3.0x+ | 2.05x–3.42x |
| ROAS Mini LED | 4.0x+ | 3.65x–6.24x |
| Costo por conversación WA | **$400** | $511–$1.181 |
| Conversaciones WA/día | 50+ | 34–80 |
| Frecuencia máxima | 3.5 | conjuntos maduros a 3.07+ |

### Filosofía operativa
1. NO tocar campañas <7 días tras un cambio (fase aprendizaje).
2. Subir presupuesto **máx +50% por vez** (más resetea el aprendizaje).
3. Testing en ABO / Escala en CBO.
4. Un ángulo GANA si: ROAS >2.5x + Compras >0.
5. Un ángulo MUERE si: gasto >$15-20k + 0 compras + <2 carritos + CTR <1%.
6. Regla de ubicación: **Mini LED INDOOR, resto OUTDOOR.**

### Cadencia semanal
Lunes análisis+decisiones · Mar/Mié brief+producción · Jue/Vie edición · Sáb prep · Dom subida a Meta.
